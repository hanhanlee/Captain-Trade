# V3 三線齊穿突破策略定義

## 一、策略概述

**V3 三線齊穿**是一種短線動能突破策略。

當股價在 5 日、10 日、20 日均線（MA5/MA10/MA20）全線以下，且三條均線高度糾結（互相靠攏）時，代表多空雙方在同一個價格帶反覆拉鋸、蓄積能量。一旦盤中股價同時向上穿越三條均線，加上成交量放大確認，即視為短線突破訊號。

---

## 二、策略邏輯

### 1. 為何關注三線糾結？

三條均線代表不同時間尺度（5 日短線、10 日中短線、20 日中線）的成本均值。三線同時靠攏，表示在這段時間持股的買方平均成本高度重疊，市場對這個價格帶有高度共識，等待一個方向。糾結時間越長、糊結度越緊，突破後的方向性通常越明顯。

### 2. 為何要「同時」突破三線？

若只突破 MA5 但未過 MA10/MA20，代表突破力道不足，上方仍有阻力。三線齊穿代表多方同時跨越三個時間尺度的壓力，勝率較單線突破高。

### 3. 量能為何必要？

無量的突破容易在隔日面對均線壓力回測，成為假突破。要求當日成交量放大（預估全日量 > 前五日均量 × 1.5），確認資金實際入場。

---

## 三、進名單條件（每日 08:50 掃描，日 K 收盤資料）

| 條件 | 說明 |
|---|---|
| 昨收 < MA5 且 < MA10 且 < MA20 | 股價在三線全線以下（等待突破而非已突破） |
| 三線糾結度 < 3% | `(max(MA5,MA10,MA20) - min(MA5,MA10,MA20)) / mid × 100 < 3%` |
| vol_ma5 存在 | 需有量能基準（前五日均量），供盤中量能計算使用 |

---

## 四、盤中推播條件（09:00–13:30 每分鐘檢查）

同時滿足以下兩個條件才推播：

**條件一：三線齊穿**
```
現價 > MA5 且 現價 > MA10 且 現價 > MA20
```

**條件二：量能放大**
```
預估全日量 > 前五日均量 × 1.5
預估全日量 = 當前累積量 × (270 / 已過交易分鐘數)
```
*台股交易時間 09:00–13:30，共 270 分鐘。elapsed 最少計算 5 分鐘，避免開盤前幾分鐘換算係數過大失真。*

## 六、注意事項

- **不驗證前置背景**：不像 N 字底要求先有明顯下跌，三線糾結可能出現在橫盤整理、短暫拉回後，需搭配大盤環境、籌碼、產業輪動判斷。
- **開盤前幾分鐘量能不穩**：預估全日量在 09:00–09:05 間係數最大，可能高估；建議搭配盤中走勢觀察。
- **只看科技股**：掃描範圍同 N 字底，限制在 9 大科技產業，降低雜訊。
- **推播後不重複**：同一股票當日只推一次（alerted_today 標記）。
