## 第二十四章：資料備份與雲端同步

> 「資料是比程式碼更難重建的東西。」

### 為什麼備份很重要

`srock.db` 是本工具的唯一資料儲存，包含所有持股、交易日誌、快取與設定。
硬碟損壞或意外刪除時，所有資料將無法復原。
自動備份腳本確保每天都有一份安全副本存在 Google Drive，且最多只損失一天的資料。

---

### 備份腳本

```
scripts/backup_gdrive.py
```

執行方式：
```bash
cd "E:\workspace\srock tool"
python scripts/backup_gdrive.py
```

---

### 備份流程

| 步驟 | 動作 |
|------|------|
| 1 | `sqlite3.backup()` 安全複製 DB（WAL 相容，不鎖表）|
| 2 | gzip 壓縮為 `temp_backup.db.gz` |
| 3 | `rclone copyto` 上傳至 `gdrive:srock_backup_YYYYMMDD.db.gz` |
| 4 | `rclone ls` 驗證雲端確實存在後刪除本機暫存 |
| 5 | `rclone delete --min-age 14d` 清除 14 天前舊備份 |

---

### 首次部署注意事項

#### 服務帳號金鑰（重要，日後勿忘）

本工具使用 Google Cloud 服務帳號授權 Rclone 存取 Google Drive。
金鑰檔案位於：

```
E:\workspace\srock tool\secrets\gcp_backup.json
```

> ⚠️ **`secrets/` 目錄已整體列入 `.gitignore`，此檔案永不提交 Git。**
> 若金鑰遺失，至 GCP Console → IAM → 服務帳號 → 新增金鑰（JSON），
> 重新下載後放回相同路徑即可，不需重新設定 Rclone。

#### 確認 Rclone Remote

```bash
rclone listremotes   # 應顯示 gdrive:
rclone ls gdrive:    # 測試連線
```
