# 股票技術分析：N 字底明確定義

## 一、N 字底是什麼？

**N 字底**是股票技術分析中的一種底部反轉型態。

它通常出現在股價經過一段下跌之後，價格先形成第一個低點，接著反彈，再回測但不跌破前低，最後向上突破前一波反彈高點。

簡單定義如下：

> **N 字底 = 下跌後，股價反彈、回測不破前低，最後突破前高的底部反轉型態。**

---

## 二、N 字底的基本結構

一個標準 N 字底通常包含四個價格點：

```text
A：第一低點 → B：反彈高點 → C：第二低點 → D：突破點
```

圖形概念如下：

```text
        D：突破點
       ／
  B：反彈高點
   ／＼
  ／  ＼
A      C
第一低點  第二低點
```

---

## 三、N 字底的嚴格定義

### 1. A：第一低點

股價經過一段明顯下跌後，形成第一個重要低點。

這個低點代表股價暫時止跌，但此時還不能確認底部成立。

---

### 2. B：反彈高點

股價從 A 點開始反彈，形成一個短線高點 B。

B 點是後續判斷 N 字底是否成立的重要壓力位。

---

### 3. C：第二低點

股價從 B 點回測，但 **C 點不能有效跌破 A 點**。

基本條件：

```text
C >= A
```

更強勢的條件：

```text
C > A
```

若 C 點高於 A 點，代表第二次回測時賣壓減弱，市場不願意再創新低，這種型態通常比單純不破底更強。

---

### 4. D：突破點

股價再次上漲，並且 **突破 B 點高點**。

這是 N 字底正式成立的關鍵條件。

成立條件：

```text
D > B
```

在沒有突破 B 點之前，只能稱為「疑似築底」或「反彈整理」，不能算是完整的 N 字底。

---

## 四、N 字底的成立條件

最基本成立條件：

```text
A 是第一低點
B 是反彈高點
C 不跌破 A
D 突破 B
```

用價格條件表示：

```text
C >= A
D > B
```

更強勢的 N 字底條件：

```text
C > A
D > B
```

---

## 五、成交量判斷

成交量不是 N 字底的必要條件，但可以用來輔助確認型態強弱。

理想的量價結構如下：

```text
A 附近：下跌量縮，或恐慌放量後止跌
A → B：反彈時成交量增加
B → C：回測時成交量縮小
D 突破 B：突破時成交量放大
```

如果突破 B 點時沒有量，或突破後很快跌回 B 點以下，則要小心是假突破。

---

## 六、什麼情況不算 N 字底？

以下情況不應該視為完成的 N 字底。

### 1. C 點跌破 A 點

```text
C < A
```

這代表股價繼續破底，型態失敗。

---

### 2. D 點沒有突破 B 點

```text
D <= B
```

這只能稱為反彈或區間整理，還不能確認 N 字底成立。

---

### 3. 突破 B 點後很快跌回 B 點以下

這種狀況可能是假突破，代表買盤追價力道不足。

---

## 七、實務判斷重點

在實務操作上，可以用以下方式判斷：

1. **先確認股價前面是否有一段明顯下跌。**
2. **找出第一低點 A。**
3. **觀察是否出現反彈高點 B。**
4. **確認回測低點 C 是否不破 A。**
5. **等待股價突破 B，才視為 N 字底完成。**
6. **若突破時有成交量放大，可信度較高。**

---

## 八、最精準的一句話定義

**N 字底是指股價在下跌後形成第一低點，反彈後回測不破前低，再向上突破前一波反彈高點，所構成的底部反轉型態。**

---

## 九、簡化公式

```text
N 字底成立：
C >= A 且 D > B
```

```text
強勢 N 字底成立：
C > A 且 D > B
```

---

## 十、注意事項

N 字底是一種技術型態，不代表股價一定會上漲。

它只能表示股價有可能完成底部結構，並出現由弱轉強的跡象。實際操作時，仍應搭配成交量、均線、籌碼、基本面與大盤環境一起判斷。
