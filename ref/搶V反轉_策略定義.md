# 搶 V 型反轉 策略定義

> 逆勢抄底型策略。與 V3/V5(順勢突破)不同,天生假訊號較多、風險較高,推播一律標「逆勢、僅供觀察」。
> 上線日:2026-08-27(整套 ①kdj → ②detector → ③db+builder → ④盤中三段 → ⑤scheduler → ⑥UI)。

## 一、核心概念

搶 V 型反轉 = 股價急跌到低檔後,出現「恐慌爆量 → 止跌 → 過高確認」的由弱轉強結構,
搭配 KD 在低檔黃金交叉,視為短線反轉進場點。

## 二、四個必備條件(使用者定義)

1. **急跌**:股價連續下跌數天,或從高點累積跌幅很深(例：從高點跌 >20%)。
2. **爆大量**:連續下跌的「低檔區」突然爆出異常大成交量(恐慌盤/買盤進場)。
3. **止跌訊號**:爆量後出現「止跌 K 線」——十字變盤線或紅 K 棒。
4. **過高(進場確認)**:止跌訊號後,一根紅 K 的**收盤價突破止跌 K 線的最高點**——這是進場確認點。
   - 通常此時 **KD 在低檔黃金交叉**（本策略列為**必要條件**）。

## 三、量化規格(定案值 — 2026-08-27)

數值取捨原則:**既有策略有對應值就沿用、沒有才用新建議**。

| 條件 | 判定 | 來源 |
|------|------|------|
| ① 急跌(OR) | 從近 **60 日**收盤高回落 **≥20%** _或_ 近 **10 日**內下跌 **≥6 天** | 60日/回撤公式沿用 portfolio;20% 用使用者原話;連跌為新增 |
| ② 低檔爆量 | 當日量 ≥ **前 5 日均量(vol_ma5) ×1.5**,且爆量日收盤落在近 **20 日**區間**下緣 30%** 內 | 1.5×5日均量沿用 scanner「量能爆發」;20日窗沿用;低檔<30% 為新增 |
| ③ 止跌K | 爆量日後(含)**3 日內**出現 十字(實體比 `|C−O|/(H−L)` ≤ **0.30**)**或**紅K(C>O);取其**最高點**為觸發價;止跌K須在最近 **2 日**內(不追舊) | 實體比公式沿用 v5;門檻/時間窗為新增 |
| ④ 過高確認 | 現價/收盤 **> 止跌K最高點(觸發價)** 且 紅K(現價>今開) | — |
| KD 濾網 | **KD(9,3,3)**:K < **30**(低檔)且 **K > D**(金叉) | 週期沿用慣例;低檔門檻為新增 |
| 流動性 gate | 前 5 日均量 `vol_ma5` ≥ **5000 張** | 沿用 N字底/v5 `MIN_LOTS` |
| 過熱濾網 | 現價 ≤ 觸發價 ×1.03(拉開太遠不追) | 沿用 `BREAKOUT_BUFFER_PCT` |

> 參數集中在 `modules/v_reversal_detector.py::VReversalParams`,實戰後可直接調(改完在「盤中V反」頁按「立即重建」驗證)。

## 四、雙相位架構(同 N 字底:盤前找型態、盤中確認突破)

- **盤前(EOD/建候選)**:①②③ + KD 低檔已成形、且**尚未突破**觸發價 → 寫入候選表。記錄止跌K最高點 = 觸發價。
- **盤中(即時確認)**:候選中誰**過了觸發價 + 紅K + KD 低檔金叉(用現價重算當日 KD) + 流動性** → ④成立 → 推播。

## 五、三段式通知(使用者要求)

| 時機 | 判定 | 推播 |
|------|------|------|
| **盤中即時**(09:00–13:30 每分鐘) | 過觸發價 + 紅K + KD 低檔金叉(現價重算) + 流動性 + 過熱 | ⚡**盤中預警**(標「未收盤、可能假突破」)+ 結構跨日去重 |
| **13:15 統整** | 對候選**當下重驗**,仍成立才列(不成立不列) | 併入既有 13:15 收盤前彙整訊息的「搶V反轉(逆勢)」軌 |
| **收盤確認**(13:40,收盤補正後) | 用**定案收盤**重驗:收盤>觸發 + 紅K + KD 日線金叉 | ✅**收盤確認**(教科書進場點) |

## 七、去重與清理

- 當日盤中預警:`alerted_today` 旗標,同檔當日只預警一次。
- 跨日:`VReversalAlertHistory`(唯一鍵 `stock_id + stabilize_date`,同一組止跌結構只預警一次)。
- 收盤確認:`confirmed_today` 旗標。
- 清理:候選 7 天、歷史 30 天。
